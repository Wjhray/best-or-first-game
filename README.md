# 《最棒的》還是《第一名》

手機友善的可操作遊戲原型。

## 已加入
- 至少 3 位玩家、玩家名稱管理
- 每位玩家輪流擔任莊家
- 莊家分配 A/B 區（含自己）
- 玩家依序私下選擇 ☝️ 或 👍
- A/B 區分別統計；少數選擇者每人 +1 分（區內少於 3 人或平手不計分）
- 分配與選擇階段倒數、總分榜、每回合結算、重設回合／整場
- 手機友善的可愛塗鴉風 UI

## 重要限制
目前是**單一裝置輪流操作**的原型。玩家需要依序傳遞同一台手機，不能讓不同手機即時加入同一房間。跨裝置線上版仍需要房間代碼、即時資料庫／後端、玩家連線狀態與伺服器端秘密選擇保護。

## 發布到 GitHub Pages
已新增 `.github/workflows/pages.yml`。到 GitHub 儲存庫的 **Settings → Pages**，將 **Build and deployment → Source** 設為 **GitHub Actions**。儲存庫若是 private，Pages 能否發布取決於帳號／方案的可用權限。設定完成後，到 **Actions** 查看部署工作流程；成功後會顯示網站網址。
