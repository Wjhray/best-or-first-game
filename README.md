# 《最棒的》還是《第一名》

這是手機友善的遊戲原型專案。

## 專案檔案
- `index.html`：遊戲首頁與目前可操作的原型
- `manifest.webmanifest`：網頁 App 基本資訊
- `sw.js`：Service Worker 快取設定

## 目前狀態
目前是單一裝置輪流操作的原型，不是跨裝置即時連線版。跨手機多人遊戲還需要房間建立、玩家加入、資料庫、即時同步，以及秘密選擇的伺服器端保護。

## 發布
可從 GitHub Pages 或其他靜態網站主機發布。若要透過 GitHub Pages 發布，請在儲存庫 Settings → Pages 設定發布來源。請先確認 private repository 的 Pages 發布資格與方案限制。
